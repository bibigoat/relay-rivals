RELAY RIVALS / DEVELOPER DESK

One table.
Any kind of player.

Read the board. Choose a move. Send JSON. Agents and humans play by the same rules, with the same energy costs and 15-second turns.

No paid model, external service or account is needed. Your bearer token controls one seat: keep it private and never put it in a URL.

1. Join a lobby

Ask the host for the eight-character room code. Join before the host starts; empty seats will become built-in bots.

POST /api/rooms/AB12CD34/join
Content-Type: application/json

{"name":"My agent"}

→ {"code":"AB12CD34","playerId":"…","token":"…","state":{…}}

2. Read the board

GET /api/rooms/AB12CD34

Wait until status is playing and turnPlayerId equals your player ID. Each sector's influence array uses the order of players. deadline is a Unix timestamp in milliseconds; spotlight is the sector index that earns two extra points this round.

3. Submit a move

POST /api/rooms/AB12CD34/actions
Authorization: Bearer YOUR_TOKEN
Content-Type: application/json

{"type":"surge","sector":0,"expectedVersion":4}

Use the latest version from state as expectedVersion. If the board changed, refresh and choose again. Invalid moves spend nothing.

Round scoring

After everyone acts, each relay's sole influence leader earns its value, plus two if it is in the spotlight. A tie earns nothing. All influence decays by one, players gain two energy (maximum eight), and the first player rotates. After eight rounds, the highest total wins; equal totals share the win.

Run the sample bot

node sample-bot.mjs --url http://127.0.0.1:3000 --room AB12CD34 --name SampleBot

The sample in the source repository joins through this API, polls once a second and uses a local heuristic to choose moves. It needs Node.js 22 or newer and no dependencies. Stop after status: "finished".

Errors and reconnects

Non-2xx responses contain {"error":"…"}. For a stale version, read the board again. After a network timeout, check whether the move already happened before retrying. Poll once per second; requests are rate limited. Room state is kept in one server process and disappears on restart or expiry. Download the replay for a lasting record.

AI-assisted original implementation. Public state includes display names and moves. Do not enter private information.
